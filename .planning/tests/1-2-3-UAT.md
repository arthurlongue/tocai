# User Acceptance Testing: Phases 1, 2 & 3

**Goal**: Verify the end-to-end pipeline (Parse -> Storage -> Audio -> Visual) for a single-track Guitar Pro file.

## Test 1: File Parsing & Storage
**Requirement**: PARSER-01, PARSER-02, BINARY-01
- [ ] **Action**: Upload a valid `.gp5` or `.gpx` file.
- [ ] **Expectation**:
    - Parsing indicator appears.
    - Song metadata (Title, Artist, Duration, Tracks) is correctly displayed.
    - File is successfully persisted (can be verified in DevTools IndexedDB if needed).
- [x] **Result**: **PASS** - Successfully parsed in main thread without DOMParser errors.

## Test 2: Audio Synthesis
**Requirement**: AUDIO-01, AUDIO-02, AUDIO-04
- [ ] **Action**: Click the "PLAY" button.
- [ ] **Expectation**: 
    - Audio context starts correctly (no silent failure).
    - Synthesized guitar sounds are heard for the notes on the track.
    - Clicking "PAUSE" stops the audio, "PLAY" resumes from the same point.
    - Clicking "STOP" resets the position to the beginning.
- [x] **Result**: **PASS**

## Test 3: Visual Synchronization
**Requirement**: VISUAL-01, VISUAL-04, VISUAL-05, AUDIO-05
- [ ] **Action**: Observe the Canvas while audio is playing.
- [ ] **Expectation**:
    - Vertical lanes (strings) match the track's tuning.
    - Note circles with fret numbers move from right to left toward the hit-line.
    - Notes pass the hit-line exactly when the corresponding audio is heard.
    - The visualizer correctly pauses and resets in sync with the transport.
- [x] **Result**: **PASS** - Canvas correctly spans full width and audio sync has been fine-tuned using latency compensation.

## Test 4: Responsiveness & Performance
**Requirement**: Performance, Responsiveness
- [ ] **Action**: Resize the browser window during playback.
- [ ] **Expectation**:
    - The Canvas resizes correctly without distorting the layout.
    - Playback remains smooth (60fps target) without audio glitches.
