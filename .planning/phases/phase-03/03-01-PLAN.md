<task type="auto">
  <name>Task 2: Implement Core Renderer Class</name>
  <files>src/engine/Renderer.ts</files>
  <action>
    Create a `Renderer` class to manage the Canvas life cycle:
    - Constructor: Accepts `HTMLCanvasElement` and optionally a `PlaybackNote[]` or `Track`.
    - `render()`: The main entry point for a single frame.
      - Clears canvas.
      - Draws string lanes (horizontal lines).
      - Draws the Hit-Line (vertical playhead).
      - Polls `Tone.getTransport().seconds`.
      - Culls and draws visible notes (circles with fret number text).
    - `start()`: Begins the `requestAnimationFrame` loop.
    - `stop()`: Cancels the loop.
    - `setTrack(track: Track)`: Updates the notes to be rendered.
    - Use `Math.floor()` for line coordinates to avoid sub-pixel blurring per RESEARCH.md.
  </action>
  <verify>

  </verify>
