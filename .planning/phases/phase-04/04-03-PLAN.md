       - Install @playwright/test
       - Install @playwright/experimental-ct-react
       - Create playwright.config.ts
       - Create playwright/index.html and index.tsx
    
    2. If playwright create doesn't work, manually install:
       ```bash
       pnpm add -D @playwright/test @playwright/experimental-ct-react
       pnpm exec playwright install
       ```
    
    3. Configure playwright.config.ts:
       ```typescript
       import { defineConfig } from '@playwright/experimental-ct-react';
       
       export default defineConfig({
         testDir: 'tests/e2e',
         timeout: 30000,
         use: {
           viewport: { width: 1280, height: 720 },
           ctPort: 3100,
           ctViteConfig: {
             // Vite config for component testing
           }
         },
         projects: [
           {
             name: 'chromium',
             use: { browserName: 'chromium' }
           },
           {
             name: 'firefox',
             use: { browserName: 'firefox' }
           },
           {
             name: 'webkit',
             use: { browserName: 'webkit' }
           }
         ]
       });
       ```
    
    4. Add test script to package.json:
       ```json
       "scripts": {
         "test:e2e": "playwright test",
         "test:e2e:ui": "playwright test --ui"
       }
       ```
